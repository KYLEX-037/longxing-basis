# 隆兴供应链｜钢材基差与期现套利

使用网址：https://kylex-037.github.io/longxing-basis/

响应式蓝黄互动讲解网页，采用 PPT 原始 Logo。选择期现正套或反套，再按“下一步”完整演示六个阶段，支持回退、重播、成本测算和离线缓存。

## 正套与反套

基差始终为现货价减期货价，保留正负号。

- 正套：买现货、卖期货；毛收益 = 离场基差 − 建仓基差。
- 反套：卖现货、买期货；毛收益 = 建仓基差 − 离场基差。

核算同时展示现货与期货两笔盈亏，以及基差差值，两种算法一致。反套假设卖出已有可用库存，再买回同量同质库存；轮换差额不含原库存历史成本对应的会计利润。

## 使用与离线

首次联网打开，等待“已备好离线版”。iPhone/iPad 用 Safari 分享菜单添加到主屏幕；华为系统浏览器中查找添加到桌面/安装应用（支持因版本而异）。先在自己的设备上开飞行模式试一次。清理缓存或系统回收存储后需重新联网。电脑可下载 longxing.html 独立文件运行。

## 部署与维护

所有文件置于 GitHub 仓库根目录，Settings → Pages → Deploy from a branch → main / (root)。无需构建、数据库或 API 密钥。model.js 为情景和计算，app.js 为六步演示，style.css 为布局，sw.js 为缓存。更新资源需同步修改 sw.js 的 CACHE 版本，等待新缓存准备完成并重新加载。
