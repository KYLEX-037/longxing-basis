# 隆兴供应链｜钢材基差与期现套利

蓝黄版互动讲解网页，适配手机、平板、电脑；六步演示、回退重播、让利及亏损情景、成本测算与风险说明。

首次联网打开后，等待“已备好离线版”，再添加到主屏幕并开启飞行模式验证。清理浏览器数据可能清除缓存。

真实案例按5000吨、现货3960→3816、期货3886→3716测算：毛收益26元/吨、合计13万元，未扣成本与联合业务分成。其余11000吨未纳入测算。让利和亏损情景属于教学假设。

发布：仓库 Settings → Pages → Deploy from a branch → main / (root)。所有文件放在仓库根目录，无需构建、依赖、数据库或API密钥。更改内容时同步更新sw.js缓存版本。
